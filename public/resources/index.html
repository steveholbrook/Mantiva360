Before you evaluate

Will the demo open without sign-in?

That behaviour is not currently verified. The demo opens at the separate Mantiva360 application address, and access requirements should be confirmed before publication.

Are all views shown in the videos current?

A complete frame-by-frame product-version and identity audit remains required. Current website claims rely on separately verified implementation evidence.

Can I submit project files?

No. The initial enquiry should collect only contact details and an optional project-control question. Do not send confidential project files through the website.
