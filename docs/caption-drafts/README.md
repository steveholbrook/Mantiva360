# Caption preparation, not accessibility certification

The supplied films contain burned-in text, H.264 video and AAC audio. There are no embedded subtitle streams or supplied sidecars. These WebVTT drafts were prepared from visible captions, with approximate timings. They are intentionally outside public/ and not linked as accurate captions.

Before release, a reviewer must listen to the complete audio, reconcile every spoken word, add meaningful sound cues and speaker labels, check timing frame by frame, and assess audio description for essential visual information. Review readability on a phone. Then place approved files in public/assets/video/ and add `captions` paths to the shared media configuration. The player supports native caption tracks. Film summaries on Resources are deliberately labelled summaries, not verbatim transcripts.

The short film is a review cut with product placeholders. Replace those inserts with verified product footage before treating the film as final. The existing three YouTube films still require independent caption/transcript verification.
