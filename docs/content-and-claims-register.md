# Content and claims register

This register keeps website positioning defensible as the product changes.

| Public statement | Basis | Boundary |
|---|---|---|
| Mantiva360 connects delivery plans, costs, forecasts, resources and risks in one project context. | Implemented Mantiva360 product modules and current navigation. | Does not claim automatic integration with every external source. |
| The 360 Cockpit highlights what needs attention. | Current GOLD2 cockpit captures show health, attention queue, reason context and corrective-action guidance. | Findings depend on current source records and configured controls. |
| Project health and reconciliation are rules-based. | Existing deterministic health and reconciliation engines. | Thresholds and source coverage must remain versioned and explainable. |
| AI helps authorised users interpret project data. | Current read-only assistant positioning. | Does not autonomously write status or remediate a project. Deployed permissions must be verified before launch. |
| Mantiva360 aligns project control to SAP Activate phases. | Product methodology settings and phase-aware delivery model. SAP publishes Discover, Prepare, Explore, Realize, Deploy and Run. | No SAP endorsement, certification or native Cloud ALM integration is claimed. |
| Mantiva360 complements existing execution tools. | Product strategy and current scope. | Data ingestion and integrations are evaluated separately. |
| GOLD2 demonstrates controlled red-to-green recovery. | Fictional GOLD2 records and captured control results from 14 September 2026. | Not a promise of one-click recovery or equivalent results on a real project. |
| Approved baseline, current forecast and actuals are distinct. | Existing planning and forecast control model. | The website illustration is explanatory and does not claim a GOLD2 financial result. |
| Actual effort and cost do not automatically create earned progress. | Canonical progress-engine rules. | Progress varies by configured project-control strategy. |

## Claims excluded from the public site

- customer testimonials or logos without permission;
- adoption counts, quantified savings or ROI without measured evidence;
- pricing before the commercial model is approved;
- SAP endorsement, certification or partnership;
- native integrations that have not been built and tested;
- anonymous demo access without verification;
- autonomous project remediation;
- “100% truth”, “zero administration”, “no setup” or similar absolute claims; and
- a successful enquiry or confirmed meeting without backend confirmation.

## Authoritative methodology source

SAP Learning identifies the SAP Activate phases as Discover, Prepare, Explore, Realize, Deploy and Run. The website links to SAP’s own methodology learning material and describes Mantiva360’s control application as independent.
